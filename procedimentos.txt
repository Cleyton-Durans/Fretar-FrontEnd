CONFIGURAR A EQUIPE PARA USAR A BRANCH DEVELOP

1. Compartilhe o repositório com a equipe (adicionando colaboradores).
2. Instrua a equipe a executar os seguintes passos:

   - Clonar o repositório:
     git clone https://github.com/seu-usuario/meu-projeto.git

   - Verificar as branches existentes:
     git branch -a

   - Configurar nome e email do usuário:
     git config --global user.name "Seu Nome"
     git config --global user.email "seu.email@exemplo.com"

   - Trocar para a branch develop:
     git checkout develop

   - Criar branches de feature a partir da develop:
     git checkout -b feature/nova-funcionalidade

   - Enviar alterações e abrir Pull Requests (PRs) para a develop.

4. BOAS PRÁTICAS

- Pull Requests (PRs): Sempre revise o código antes de mesclar na develop.
- Atualize a develop: Antes de começar uma nova feature, execute:
  git pull origin develop
- Nomenclatura de Branches: Use prefixos como feature/, bugfix/ ou release/ para organizar.

5. EXEMPLO DE FLUXO DE TRABALHO

Estrutura de Branches:
- main: Branch estável (produção).
- develop: Branch de integração (testes).
- feature/*: Branches de desenvolvimento (ex: feature/login).

Passo a passo para uma nova tarefa (ex: Criar tela de login):

1. Garanta que está na develop atualizada:
   git checkout develop
   git pull origin develop

2. Crie e mude para a nova branch de funcionalidade:
   git checkout -b feature/login

3. Desenvolva a funcionalidade e faça commits.

4. Envie a branch e crie o Pull Request no GitHub para mesclar com a develop.
